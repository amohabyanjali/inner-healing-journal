## Technical Specifications

### SVG Standards
- **Format**: Scalable Vector Graphics (SVG)
- **Compatibility**: All modern browsers, PDF generators
- **Optimization**: Clean, hand-coded SVG (no unnecessary metadata)
- **Text Rendering**: Web-safe fonts with fallbacks
- **Color Format**: Hex codes for consistency

### Font Stack
```css
Primary (Headings): 'Playfair Display', Georgia, serif
Secondary (Body): 'Lato', Arial, sans-serif
Fallback: System fonts
```

### Sizing Guidelines
- **Full Page Graphics**: 800×1000px (portrait)
- **Square Graphics**: 600×600px or 800×800px
- **Cards**: 350×200px (landscape)
- **Decorative**: Variable (optimized for purpose)

### Export Settings
- **Resolution**: Vector (scalable)
- **Stroke Width**: 2-3px (standard)
- **Border Radius**: 10-15px (rounded corners)
- **Opacity**: 0.2-0.8 (backgrounds), 1.0 (foreground)

```javascript

  fs.writeFileSync(path.join(graphicsDir, 'filename.svg'), svg);
```
